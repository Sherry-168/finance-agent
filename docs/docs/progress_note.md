日期：2026-11-19

当前状态

* 记账功能：已完成
* 自然语言查账模块：正在开发

已完成工作

1. 在 Dify 中搭建查账功能的基础 Workflow。
2. 配置 LLM 节点，使用 deepseek-v4-pro 模型识别用户的自然语言查询。
3. 完成 LLM 节点的 JSON Schema 结构化输出配置，约束查询字段及数据类型。
4. 设计并配置以下四个查询字段：
    * time_range：时间范围，无时间条件时为 null。
    * categories：消费分类数组。
    * agg：聚合方式，包括 sum、count、max。
    * group_by：分组维度，没有分组要求时为 null。
5. 已进行自然语言查询测试，初步验证了时间范围、消费类别和聚合方式的提取。

当前设计思路

* 由 LLM 负责理解用户的自然语言，并提取查询条件。
* 金额计算、数据统计和实际查询交给后端执行。
* 通过固定的结构化输出格式，为后续后端接口对接提供统一的数据。
